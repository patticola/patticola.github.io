## patticola.github.io

A simple portfolio page written entirely in vanilla JavaScipt, HTML, and CSS.

I wanted a clean, readable design that showcased a few recent-ish personal projects, the technologies I used to make them, and some lessons I learned along the way.

Most of the elements on the page are dynamically loaded based on the contents of site-data.js, which operates as the site's "back-end."
